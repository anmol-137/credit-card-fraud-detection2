# Dataset

The dataset is not stored in this repository (150 MB, over GitHub's file-size limit).

1. Download **Credit Card Fraud Detection** from Kaggle: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Unzip it and place `creditcard.csv` in this folder (`data/creditcard.csv`).

Only needed for retraining (`python ml/train.py`) and the notebook. The web app runs without it, because the trained model is committed in `models/`.
